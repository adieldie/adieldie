## O que construo

- **Automações e integrações:** processamento de pedidos, sincronização de informações e recuperação de falhas.
- **Dados e operação:** conferência de estoque, comparação de custos e relatórios para apoiar decisões.
- **Ferramentas de suporte:** diagnóstico de impressão, interfaces de acompanhamento e documentação técnica.

Trabalho com **Python, JavaScript, SQL, APIs HTTP, HTML e CSS**. Uso ferramentas como Flask, FastAPI, Selenium e Docker conforme a necessidade do projeto.
